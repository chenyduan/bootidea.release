# Bootidea

**让想法，成为行动。**

[English](README.md) | 简体中文

你的本地优先 AI 桌面。

从熟悉的桌面出发，让 AI 融入日常工作。Bootidea 希望帮你把脑海中的想法，一步步变成手中完成的事。

### 本地优先，AI 相伴

- **从你的工作现场出发。** 围绕本地工作流，构建贴近日常的桌面体验。
- **让智能融入过程。** 将 AI 辅助带入工作，让思考与行动自然衔接。
- **让想法继续向前。** 减少从产生想法到迈出下一步之间的阻力。
